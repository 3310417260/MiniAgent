# MiniAgent Project Instructions

- This project is a Go learning project for building a minimal agent harness.
- Prefer clear, small, standard-library implementations.
- Keep tool implementations conservative and read-only unless write access is explicitly requested.
- Add concise comments for learning-critical logic, especially around messages, tools, sessions, and context.
- Preserve the existing CLI-first workflow.
- Run `gofmt` and `go test ./...` after code changes.
- Explain important design choices in Chinese when helping the learner.
